REPORT SERVER 시작 화면

/pe/에서 MDDI·PDDI·PMIC·SECURITY·TCON 타일을 눌러 해당 Product Type의 검색 화면으로 이동합니다. HONEY 다운로드와 전체 세션 수, 최근 7일 신규·수정 활동, 오늘 사용량, 최근 5분 접속자도 확인할 수 있습니다.

웹 로그인과 권한

접속 상태가능한 작업설정 방법
비로그인 브라우저공개 보고서 검색·읽기수정 기능은 읽기 전용입니다.
웹 로그인내 권한 범위의 즐겨찾기·편집·비공개 열람singleID와 숫자 4자리 비밀번호를 사용합니다.
Honey 접속Honey 신원으로 자동 로그인, 업로드·편집별도 로그인 없이 현재 Windows 계정을 사용합니다.
위임 편집자코멘트·상태·Note 등 콘텐츠 편집업로더가 리포트 설정의 권한 탭에서 지정합니다.

Honey 사용 이력이 없는 미사용 singleID만 웹에서 회원가입할 수 있습니다. 이미 Honey 사용 이력이 있다면 계정 선점을 막기 위해 Honey 앱에서 4자리 비밀번호를 설정·재설정해야 합니다.

사용자 이름(실명)은 회원가입 때 함께 입력하며, 아직 등록하지 않았다면 접속 시 입력창이 뜹니다. 업로더 표시·권한 부여 창 등 사람이 보이는 모든 화면이 이름(ID) 형식으로 표시되어 누구인지 바로 알 수 있습니다. 이름은 표시용이며 권한 판정에는 쓰이지 않습니다. 나중에 바꾸려면 화면 오른쪽 위 👤 버튼을 누르세요.

비공개 보고서는 업로더와 위임 편집자 외에는 목록과 상세 모두 보이지 않습니다.

Rawdata 편집 허브

페이지세부 기능원본 변경
현재 상태적용 중인 전처리·수율 기준·셀 패치를 확인하고 하나씩 또는 전체 해제합니다. 해제 후 저장해야 반영됩니다.없음
OptionsBin1 only, mean ± kσ Outlier 제거, 선택 source의 특정 DUT 제외없음
Item Select제외·표시 두 목록에서 리포트에 남길 항목을 정합니다. 검색은 목록을 숨기기만 하며 실제 이동 후 저장해야 적용됩니다.없음
Yield 계산source별 수율 분모를 자동·Gross Die·Test data에서 고르고 그 자리에서 예상 수율을 확인합니다.없음
Rawdata 원본 수정수정할 source를 체크해 Excel로 열고 값 수정·행 변경·source 시트 삭제 후 변경 검토를 거쳐 반영합니다.직접 변경

Options·Item Select·Yield 계산은 원본 parquet을 바꾸지 않는 가역 전처리입니다. 저장하면 Summary·Yield·CPK·Issue Table·Distribution·Trim·Map이 같은 기준으로 다시 계산되며 현재 상태에서 되돌릴 수 있습니다.

Excel 원본 수정 절차

  1. 먼저 Excel Down으로 현재 자료를 별도 보관합니다.
  2. Rawdata 편집 허브에서 수정할 source를 1개 이상 선택합니다.
  3. Excel에서 값을 수정합니다. source 시트를 삭제하면 그 source 자체가 보고서에서 제거됩니다.
  4. 파일을 저장하고 Excel을 닫습니다.
  5. 변경 검토의 개요·셀 변경·자동 교정·경고를 확인하고 반영을 명시적으로 누릅니다.

원본 수정은 화면에서 되돌릴 수 없습니다. 서버에는 직전 한 세대의 수동 복구용 백업만 남으므로 잘못 반영했다면 추가 편집 전에 관리자에게 즉시 문의하십시오.

웹 리포트의 Raw Data 탭은 현재 사용하지 않습니다. Rawdata 조회·전처리·원본 수정은 Honey의 Rawdata edit를 사용하십시오.
