6. Excel 연동 기능

기능입력결과
Excel Down현재 열려 있는 Web Report저장 위치를 선택해 Excel 파일로 저장
Excel UploadHONEY에서 생성한 Excel 파일Raw Data로 새 Normal Web Report 생성
Rawdata edit현재 열려 있는 Web ReportExcel에서 Raw Data 수정 후 저장·닫으면 현재 보고서 갱신

Excel Down

  • Bin1 옵션은 Distribution·Histogram에만 적용됩니다.
  • 파일 저장 위치와 이름을 직접 선택합니다.

Excel Upload

  • Raw Data Sheet가 있는 HONEY Excel 파일을 선택합니다.
  • Issue_table Comment가 있으면 함께 가져옵니다.
  • Raw Data Sheet가 없으면 Excel Report에서 Raw Data를 포함해 다시 생성합니다.

Rawdata edit

  1. 수정할 Web Report를 엽니다.
  2. Rawdata edit를 누릅니다.
  3. 열린 Excel에서 값을 수정합니다.
  4. Excel 파일을 저장하고 닫습니다.
  5. 보고서 갱신 완료 메시지를 확인합니다.

주의: Rawdata edit는 현재 보고서를 직접 갱신합니다. 실행 전 Excel Down으로 원본을 보관하십시오.

19. 문제 해결

증상확인·조치
Web Report 버튼이 실행되지 않음입력 파일, Product Type, 모드별 파일 개수를 확인합니다.
Product를 선택할 수 없음Product Type과 Family를 다시 선택한 뒤 Product 목록을 확인합니다.
Compare 생성 오류파일이 정확히 2개인지, 순서가 After → Before인지 확인합니다.
DUT 생성 오류입력 파일이 정확히 1개인지 확인합니다.
Bin1 분석 오류입력 데이터에 BIN=1 값이 있는지 확인합니다.
