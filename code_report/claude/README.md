## 핵심 결론 (3줄)

1. **코멘트 품질은 이미 "쌓일수록 좋아지는" 구조다** — IssueTable 사람 코멘트 → eval DB(label)
   → 선례검색 → AI Comment 인용의 선순환 뼈대가 연결되어 있고 설계가 건실하다.
2. **판정 정확도는 아직 아니다** — status 판정은 DB 와 무관한 고정 룰이고, 데이터로 임계값을
   개선하는 유일한 경로(calibrate)는 재료(features)가 현재 운영 흐름에서 전혀 쌓이지 않는다.
3. **끊어진 고리 4개(+리스크 1개)를 이으면 완성된다** — 대부분 eval_analyzer 를 **수정하지 않고**
   report_server 쪽 추가만으로 가능하다. 실행 순서는 06 문서 로드맵 참조.
